SurfaceCobalt

Une compagnie d'agents IA qui pilote clients, missions et factures.

Version —
⬇ Télécharger pour macOS

macOS 14 ou plus récent · Apple Silicon & Intel

Agents IA en parallèle

  • Plusieurs agents autonomes à la fois — chacun son fil d'exécution, sa file de tâches et sa boîte aux lettres ; aucun verrou global, c'est la réclamation atomique d'une tâche en base qui empêche deux agents de se marcher dessus.
  • Boucle conversationnelle complète — appel au modèle, exécution d'outils, mise à jour de la base et streaming vers l'interface à chaque tour, avec délégation possible entre agents.
  • Compatible OpenAI et modèles locaux — clé API classique ou LM Studio sur le réseau local, à coût nul.

Des outils réels

  • Shell, calendrier et rappels macOS, recherche web — les agents agissent sur de vrais outils, pas des simulations.
  • Pont MCP (Model Context Protocol) — branche des serveurs externes sans code supplémentaire.
  • Vault de fichiers avec recherche sémantique — lecture/écriture dans un espace de documents indexé par embeddings.

Gestion du Collectif Cobalt

  • Missions, clients, prospects, factures, équipes — tout le domaine métier vit dans une base SQLite locale (GRDB).
  • Suivi du coût par agent et par mission — chaque appel de modèle est rattaché à ce qu'il a servi.
  • Dictée vocale locale — capture rapide via le framework Speech d'Apple, sans rien envoyer ailleurs.

1. Décompresse le zip, glisse SurfaceCobalt.app dans Applications.
2. Au premier lancement, macOS affiche « développeur non identifié » — fais clic droit → Ouvrir, puis confirme. C'est normal, l'app n'est pas distribuée via l'App Store.
3. Les mises à jour suivantes se font toutes seules.
